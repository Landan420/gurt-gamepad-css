# Gurt gamepad CSS

Xbox One controller theme for [gamepadviewer.com](https://gamepadviewer.com), matching the Gogurt Twitch look: dark card, red and orange stripes, pink Gurt accents, and embers drifting off the controller.

**Themed Xbox One skin** (recommended):
```
https://gamepadviewer.com/?p=1&s=1&editcss=https://raw.githubusercontent.com/Landan420/gurt-gamepad-css/main/gurt-xbox.css
```

**Full custom skin** (drawn entirely in CSS, with the panel stripes across the grips):
```
https://gamepadviewer.com/?p=1&css=https://raw.githubusercontent.com/Landan420/gurt-gamepad-css/main/gurt-xbox.css
```

Add either link to OBS as a Browser Source (width 750, height 630).
